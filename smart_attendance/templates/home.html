Smart Attendance Management System

Automated attendance tracking with Make-Up class scheduling and Remedial Code verification for B.Tech CSE students.

Login

Student & Faculty accounts are created by the System Admin only.

System Features

One-Click Attendance

Faculty can mark attendance for entire class in seconds. Absent students are automatically detected and logged.

Instant Notifications

Students receive automatic in-app alerts when marked absent. Make-Up class notifications are sent instantly.

Remedial Code Module

Faculty generates unique 6-character codes for make-up classes. Students enter the code to mark their attendance.

Detailed Reports

View subject-wise attendance percentage, date-wise records, and low-attendance warnings.

Role-Based Access

Separate dashboards and permissions for Students, Faculty, and Admin. Secure login system.

Analytics Dashboard

Visual charts showing attendance trends, subject-wise statistics, and prediction insights.

How It Works

1
Faculty Marks Attendance

Select subject and date, check present students, submit.

2
Automatic Absentee Detection

System auto-marks unchecked students as absent and logs them.

3
Student Gets Notified

Absent students see an in-app alert immediately.

4
Faculty Schedules Make-Up Class

Faculty creates a session with an auto-generated remedial code.

5
Student Enters Code

Student enters the code before it expires. Attendance recorded separately.

Complete attendance lifecycle managed in one system
